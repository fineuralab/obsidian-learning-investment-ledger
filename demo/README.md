# Demo data / 独立演示数据

These synthetic examples are separate from personal records. Each language contains four investments, thirteen events and eleven linked notes, anchored to 2026-11-02. Net spending is **CNY 797**.

- [English examples](en/Investment%20Ledger/演示数据/)
- [中文示例](投入账本/演示数据/)

Use **Load demo data / 载入演示数据** inside the plugin to create dates relative to today and paths for your chosen ledger folder. Existing demo content is preserved; clear and reload it to change language. The real ledger never loads these files automatically.

The English and Chinese examples deliberately share stable demo IDs. **Do not copy both into the same ledger.** `npm run demo` regenerates both sets.

这些演示内容是虚构示例，与用户真实记录分开。每套包含四项投入、13 条事件和 11 篇关联笔记，净支出为 **797 元**。建议使用插件内的「载入演示数据」，按今天和当前数据目录生成正确链接；已有演示内容不会随语言切换改写，清除后可重新载入。两套示例的固定 ID 相同，请勿同时复制到同一账本。
